Fungsi: Menghitung rata-rata nilai ujian dari sejumlah siswa.
Cara Kerja:
• 	Pengguna memasukkan jumlah siswa dan nilai masing-masing.
• 	Program menjumlahkan semua nilai dan membagi dengan jumlah siswa.
• 	Rata-rata ditampilkan sebagai hasil akhir.
